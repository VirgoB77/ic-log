# 高速IC 乗降記録

高速道路のどのICから乗って、どのICで降りたかを、ボタン1回で記録するスマホ用アプリ。
経費精算や訪問記録のために、月ごとの履歴をメール・LINE・CSVで送れる。

## 使い方

1. スマホのブラウザでアプリを開く（下記の「公開版」）。
2. 高速に乗る直前・降りた直後に、停車して大きいボタンを押す。
   - **乗った（緑）** … 高速道路へ入る
   - **降りた（青）** … 一般道へ出る
3. 現在地から一番近いICを自動で判定し、日時と一緒に保存する。
4. 違うICになったら、下のカードの「直す」から変更する。
5. 月末に「送る」タブで期間を選び、メール／LINE／CSVで送る。

色は道路案内標識に合わせている（高速＝緑、一般道＝青）。

### スマホ用（GitHub Pages）

https://virgob77.github.io/ic-log/

ホーム画面に追加しておくと、アプリのように1タップで開ける。

埋め込み表示のページ（iframe の中）では、ブラウザが位置情報を渡さないため
自動判定が働かない。必ず単独のページとして開くこと。

### ローカル版

`index.html` をブラウザで開くだけで動く。1ファイルで完結している。

## 仕組み

- 全国 5,831 か所のIC（入口・出口）の緯度経度をHTMLの中に持っている。
  判定は端末内で完結するので、**圏外でも動く**（GPSは通信不要のため）。
- 記録はブラウザの localStorage に保存する。サーバーには何も送らない。
- 入口→出口を自動でペアにして「トリップ」として集計する。

### 制限

- **バックグラウンドでの自動検知はできない。** ブラウザは画面を閉じている間の
  GPS取得が許されていないため、IC通過を自動で拾うにはネイティブアプリが必要になる。
  そのため「停車してボタン1回」という形にしている。
- 記録は端末内にしかない。機種変更のときは「送る」タブでCSVを書き出しておく。
- LINEへの送信は共有画面が開く方式。LINE Notify は2025年3月に終了したため、
  自動でメッセージを飛ばすには LINE 公式アカウント（Messaging API）の登録が必要。

## ファイル構成

| パス | 中身 |
| --- | --- |
| `index.html` | 完成品。これだけで動く |
| `src/app.html` | アプリ本体のひな形（`__IC_DB__` にIC一覧が差し込まれる） |
| `data/ic.tsv` | IC一覧（名前・番号・緯度・経度） |
| `tools/build.sh` | `src` と `data` から `index.html` を生成する |
| `tools/fetch-ic.sh` | IC一覧を OpenStreetMap から取り直す |
| `dist/artifact.html` | 公開用（`build.sh` が生成） |
| `tenant/` | 2つ目のアプリ「ゆうちメモ」（テナント誘致の連絡メモ）。単体で動く |
| `card/` | 3つ目のアプリ「めいしばこ」（名刺管理）。単体で動く |
| `stoploss/` | 「損切りの山の逆張り」を過去データで検証した報告書とプログラム。単体で読める |

### 作り直すとき

```bash
bash tools/build.sh
```

新しいICが開通してデータを更新したいとき:

```bash
bash tools/fetch-ic.sh && bash tools/build.sh
```

## 2つ目のアプリ：ゆうちメモ（テナント誘致）

電話が来たらその場で書くためのメモ帳。書いた時刻が自動で残り、
誰から・いつ・どんな連絡があったかがそのまま記録になる。
メモは相手と案件にひもづいて、エクセルの推進表の形に自動で積み上がる。
同じ作り（1ファイルで完結・端末内に保存・スマホ用）で `tenant/` に入れてある。

- 使い方: [tenant/README.md](tenant/README.md)
- 公開版: https://virgob77.github.io/ic-log/tenant/

## 3つ目のアプリ：めいしばこ（名刺管理）

名刺を撮るだけのアプリ。**名前も会社も電話番号も、写真から自分で読みとる。**
輪ゴムで縛った束を、ポケットの中に持ち歩けるようにしたもの。
画面はひとつだけで、撮ることと探すことしかしない。

読み取りは Tesseract を端末の中（WebAssembly）で動かしている。
写真もサーバーには送らない。まちがえることもあるので、上に出ている名刺の写真と
見くらべて、ちがうところだけ直す。読み取った文字は候補として並ぶので、押すだけで入る。

1ファイルで完結し、記録は端末内に置く。名刺の写真だけは大きいので、
localStorage ではなく IndexedDB に入れている。

- 使い方: [card/README.md](card/README.md)
- 公開版: https://virgob77.github.io/ic-log/card/

名刺アプリを使うのが初めてなら、README の
「便利なところ」「不便なところ・できないこと」を先に読むとよい。

## 3つの保存場所は別

高速IC記録・ゆうちメモ・めいしばこは、それぞれ別の場所に記録する。
同じ端末で3つとも使っても混ざらない。バックアップもアプリごとに取る。

## 4つ目：損切りの山の逆張りを検証（相場）

「含み損を抱えた人が損切りをしたら、相場は逆に行く」を逆手にとって勝てるのか。
ビットコイン・ドル円・ポンド円・ユーロドルの過去データに当てはめて数えた。
結論は「短い時間では儲からない。ビットコインの日足で投げ売りの翌日に買うのだけプラスだが、
上げ相場に偏っていて聖杯ではない。損切りの山の安値は7〜8割の確率でまた割られる」。

- 報告書: [stoploss/index.html](stoploss/index.html)（公開版: https://virgob77.github.io/ic-log/stoploss/ ）
- 作り方・データの出どころ: [stoploss/README.md](stoploss/README.md)
