# 高速IC 乗降記録

高速道路のどのICから乗って、どのICで降りたかを、ボタン1回で記録するスマホ用アプリ。
経費精算や訪問記録のために、月ごとの履歴をメール・LINE・CSVで送れる。

## 使い方

1. スマホのブラウザでアプリを開く（下記の「公開版」）。
2. 高速に乗る直前・降りた直後に、停車して大きいボタンを押す。
   - **乗った（緑）** … 高速道路へ入る
   - **降りた（青）** … 一般道へ出る
3. 現在地から一番近いICを自動で判定し、日時と一緒に保存する。
4. 違うICになったら、下のカードの「直す」から変更する。
5. 月末に「送る」タブで期間を選び、メール／LINE／CSVで送る。

色は道路案内標識に合わせている（高速＝緑、一般道＝青）。

### 公開版（スマホ用）

https://claude.ai/code/artifact/d60d74b2-15f1-4d82-aa83-5d42d99e428d

ホーム画面に追加しておくと、アプリのように1タップで開ける。

### ローカル版

`index.html` をブラウザで開くだけで動く。1ファイルで完結している。

## 仕組み

- 全国 5,831 か所のIC（入口・出口）の緯度経度をHTMLの中に持っている。
  判定は端末内で完結するので、**圏外でも動く**（GPSは通信不要のため）。
- 記録はブラウザの localStorage に保存する。サーバーには何も送らない。
- 入口→出口を自動でペアにして「トリップ」として集計する。

### 制限

- **バックグラウンドでの自動検知はできない。** ブラウザは画面を閉じている間の
  GPS取得が許されていないため、IC通過を自動で拾うにはネイティブアプリが必要になる。
  そのため「停車してボタン1回」という形にしている。
- 記録は端末内にしかない。機種変更のときは「送る」タブでCSVを書き出しておく。
- LINEへの送信は共有画面が開く方式。LINE Notify は2025年3月に終了したため、
  自動でメッセージを飛ばすには LINE 公式アカウント（Messaging API）の登録が必要。

## ファイル構成

| パス | 中身 |
| --- | --- |
| `index.html` | 完成品。これだけで動く |
| `src/app.html` | アプリ本体のひな形（`__IC_DB__` にIC一覧が差し込まれる） |
| `data/ic.tsv` | IC一覧（名前・番号・緯度・経度） |
| `tools/build.sh` | `src` と `data` から `index.html` を生成する |
| `tools/fetch-ic.sh` | IC一覧を OpenStreetMap から取り直す |
| `dist/artifact.html` | 公開用（`build.sh` が生成） |

### 作り直すとき

```bash
bash tools/build.sh
```

新しいICが開通してデータを更新したいとき:

```bash
bash tools/fetch-ic.sh && bash tools/build.sh
```
