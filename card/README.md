# めいしばこ（名刺管理）

**名刺を撮るだけ。** 名前も会社も電話番号も、写真から自分で読みとる。
輪ゴムで縛った束を、ポケットの中に持ち歩けるようにしたもの。

画面はひとつだけ。撮る、探す、それだけ。

## 使い方

1. **「名刺を撮る」** を押すと、アプリの中にカメラが開く。**枠に名刺を合わせて**まん中の丸を押す。
   まわりに机が写っていても構わない。**名刺の枠だけを見つけて切り取り、まっすぐに直す。**
   （**シャッター音は鳴らない。** 相手の前でも、静かなところでも撮れる）
2. 文字を読みおえると、名前・会社・電話・メール・住所が**すでに入っている**。
   ちがうところだけ直す。欄の下の**候補**を押せば、打たずに入れ替えられる。
3. **どこで会ったか**と**ひとことメモ**を書く。ここは読み取れないので自分で書く。
   ここがいちばん効くところなので、一言でも入れておくとよい。
4. **「名刺箱にしまう」**。以上。

探すときは検索欄に打つ。名前の一部でも、会社でも、場所でも、**メモの中身**でも引ける。
名刺をひとつ押すと、電話・メール・地図がその場から使える。
メモはあとからでも「直す」から書き足せる。

## 見かた（写真／一覧）

検索欄の下で、並べ方を切り替えられる。選んだほうを覚えている。

| | 中身 |
| --- | --- |
| **写真** | 名刺の写真を2列に並べる。顔と一緒に「この名刺だ」と思い出せる |
| **一覧** | 名前・会社・**メモ**・会った日と場所を1行ずつ。ぱっと見て探すとき |

たくさん入ってきたら「一覧」のほうが速い。メモを書いておくほど効いてくる。

### 撮るコツ

**枠いっぱいに大きく写す**のがいちばん効く。名刺が小さく写るほど、文字に使える
画素が減って読みちがえる。明るいところで、なるべく真上から。
少しくらい斜めでも、切り出すときにまっすぐに直す。

うまく切れなかったときは、写真のすぐ下の **「切り直す」** で四隅を手で合わせられる。
横向きの名刺を縦に撮ってしまったら **「回す」**。どちらもその場で読み直し、
打ちかけの文字は消えない。

毎回自分で確かめたいときは、**設定 → 撮ったあと → 「切り取りを毎回たしかめる」** を入にする。
撮るとすぐ四隅の画面が出るようになる。

## 文字の読み取りについて

読み取りは Tesseract（オープンソースの文字認識）を**端末の中で**動かしている。
写真はどこにも送らない。読み取りの精度は、ざっくりこんな具合。

| よく読めるもの | 苦手なもの |
| --- | --- |
| 会社名・部署・役職 | 手書きの文字 |
| 名前（いちばん大きい字を名前とみなす） | 飾り文字・極端に細い書体 |
| 電話・携帯（FAXは電話に入れない） | 縦書きの名刺 |
| 住所・郵便番号 | 暗い写真、ぶれた写真 |
| メール・サイト | ロゴの中の文字 |
| | **数字**（0と9、桁の増減） |

**まちがうこともある。** とくに弱いのは**数字**とメールアドレスの `@`。
`090` が `099` になったり、桁がひとつ増えたりする。`@` は `Q` や `G` と読みちがえやすい。
電話番号は「TEL」「携帯」と書いてある行なら、多少あやしくても欄に入れて出す。
空欄にされるより、1文字直すほうが早いため。
おかしいと思ったら、上の名刺の写真とその場で見くらべて直せばよい。
まったく読めなくても、**写真は残る**ので、名前だけ手で入れてしまえばよい。

### 名前と会社は、もう一度読み直す

名刺ぜんぶを一度に読むと、大きな字の名前ほど読みちがえやすい。そこで、
名前と会社の行だけを切り出し、読みやすい大きさにして**もう一度読む**。
読み直しのほうが確からしければそちらを使い、どちらも候補に並べる。
変わった書体で「濾辺」と読めた名前が、読み直しで「渡辺」に直った。

段組みの見立て（Tesseract の PSM）がちがうと拾える行がちがうので、
2通りで読んで足し合わせている。名前が「小野寺」「誠」のように横に割れたときは
同じ高さの行をつないでから読み直す。名前は**いちばん字が大きい行**を選び、
信頼度は足切りにだけ使う（信頼度で選ぶと、小さな肩書きの行を名前にしてしまう）。

### かならず長方形に切る

名刺の四隅は、点をひとつずつ拾うのではなく、**その紙をぜんぶ囲む「面積が最小の長方形」**
としてさがしている。こうすると角が丸い名刺でも、角に影がかかっていても、切り出した絵が
かならず直角になる。点で拾う方式だと、角が丸いだけで最大6度ゆがんだ。

### 切り出すと、読めかたが変わる

写真ぜんぶ（机ごと）を読ませると、文字に使える画素が半分以下になって間違える。
名刺の枠だけを切り出してまっすぐに直すと、同じ写真でもここまで変わる。

| | 切らずに全体を読む | 名刺だけ切り出す |
| --- | --- | --- |
| 社名 | 株式会社ヤマ**タ**商事 | 株式会社ヤマダ商事 |
| 電話 | 03-5555-**6000** | 03-5555-0000 |
| 役職 | 代表取締**彼** | 代表取締役 |
| 住所 | 中区**染**3-2-**!** | 中区栄3-2-1 |

（傾き3〜5度・机の上に置いた名刺で試した結果）

### 市販の名刺アプリとの違い

myBridge や Eight のような市販のアプリは、**撮った写真を会社のサーバーに送って**、
そこで大きなAIが読む。**読み取りの正しさでは向こうが上**。
このアプリは端末の中だけで読むので、そこまでは届かない。
そのかわり、**名刺が外に出ない**。取引先の連絡先を他社に預けなくてよい。

正確さがいちばんなら市販のものがよい。預けたくないならこちら、という違い。

### はじめの一回だけ、取り込みがある

文字を読む部品と日本語の辞書で、**5MBほど**を最初に取り込む。一度すめば次からは要らない。
外で慌てないように、**設定 → 文字を読む準備 → 「いま準備しておく」**で
家のWi-Fiのうちにすませておくとよい。

電波が届かないところで初めて撮ると読み取りはできないが、**写真はちゃんと残る**。

## 輪ゴムの束と比べて、便利なところ

- **打たなくてよい。** そこがいちばん違う。撮れば入る。
- **探せる。** 「たしか名古屋の展示会で会った印刷屋の人」——これで出てくる。
  ひらがな・カタカナ、全角・半角、「株式会社」のあるなしは区別しない。
- **持ち歩ける。** 束は引き出しの中だけ。これは出先で見られる。
- **紙には書けないことが残る。** 会った日・場所・顔の特徴。
  半年後に電話をかけるとき効くのは、名刺の文字よりこのメモのほう。
  「一覧」で並べるとメモまで出るので、名前を忘れていても中身から見つかる。
- **そのまま電話・メールできる。** 番号をタップすればかかる。打ち間違えない。
- **スマホの電話帳に移せる。** 着信のときに名前が出るようになる。
- **エクセルに出せる。** 年賀状や案内状の宛名に使える。

## 不便なところ・できないこと

- **読み取りはまちがえる。** 上のとおり。目で確かめる手間はなくならない。
- **この端末の中だけ。** パソコンと共有はできない。人にも渡せない（CSVでなら渡せる）。
- **黙って消えることがある。** iPhone の Safari は、しばらく開いていないサイトの
  データを消してしまうことがある。**ホーム画面に追加して**ときどき開き、
  **月に一度バックアップ**を取ること。これだけは省かないほうがよい。
- **写真は場所を食う。** 1枚あたり100KBくらい。設定に、いま使っている量が出る。
- **相手の異動や昇進は教えてくれない。** そこは大手の名刺サービスの仕事。
- **縦書きの名刺は苦手。** 写真は残るので、名前だけ手で入れる。

### 紙の名刺は、すぐには捨てないほうがよい

慣れるまでの半年くらいは、束も残しておくとよい。
写真がぶれていた、バックアップを取り忘れた、というのは最初のうちに起きる。
「アプリを開けば全部ある」と自分で思えるようになってから、束を捨てればよい。

### 始め方（おすすめ）

いまの束を全部入れようとすると、たいてい途中でやめてしまう。
**これからもらう分だけ**入れて、あとは**よく電話する相手を10枚ほど**遡って入れる。
それで日常の用は足りる。残りは必要になったときに1枚ずつ。

## 設定（右上の⚙）

| 項目 | 中身 |
| --- | --- |
| 連絡先に入れる | 全員分を .vcf で書き出す。開くと電話帳に登録できる |
| エクセルに出す | 名簿のCSV。A1に貼れば表になる |
| バックアップ | 写真つき（完全な控え）／文字だけ（軽い）。復元もここから |
| 文字を読む準備 | 初回の取り込みを先にすませておく |
| お試し | 架空の名刺5枚を入れて動きを見る。全消しもここ |

1人だけ電話帳に入れたいときは、その名刺を開いて「連絡先に入れる」。
このときは**名刺の写真も一緒に**入るので、電話帳でも名刺が見られる。

## 仕組み

- 名前やメモは localStorage、名刺の写真は IndexedDB に置く。**どちらも端末の中だけ。**
- 文字の読み取りも端末の中（WebAssembly）。写真をサーバーに送ることはない。
- 取り込むとき、写真は長辺1400pxに縮めて保存する。読み取りには2000pxに拡大し、
  白黒にして濃淡を強めたものを使う。
- 高速IC記録・ゆうちメモとは保存場所が別（キーは `meishi.v1`）。同じ端末で3つとも使える。

### 読み取りの部品を自分で置きたいとき

ふだんは CDN（jsDelivr）から取ってくる。自分のサーバーに置きたいときは、
`?ocr=（置いた場所）` を付けて開く。置き場所には次を入れておく。

```
tesseract.min.js      … npm の tesseract.js@5.1.1 の dist から
worker.min.js         … 同上
core/                 … npm の tesseract.js-core@5.1.1 の *.wasm.js を全部
lang/jpn.traineddata.gz … npm の @tesseract.js-data/jpn の 4.0.0_best_int から
```
