# めいしばこ（名刺管理）

**もらった名刺を、その場で撮ってしまうだけ。** あとから名前でも会社でも
「あの展示会の人」でも探せる。輪ゴムの束を、ポケットの中に持ち歩けるようにしたもの。

## 使い方

1. 名刺をもらったら、アプリを開いて **「名刺を撮る」**。
2. 名前と会社を打つ。**打たなくてもよい**（写真は残る。名前はあとから入れられる）。
3. 「どこで会った」を書く。同じ展示会で何枚ももらうときは、
   一度書けば **次からはボタンひとつ**で選べる。
4. 顔や話の中身を **ひとことメモ**に書く。ここがいちばん効く（下記）。
5. **「しまう」** を押す。場所と日付はそのまま残るので、次の1枚がすぐ撮れる。

探すときは「さがす」タブ。名前の一部でも、会社でも、場所でも、メモの中身でも引ける。

### 名刺を撮るコツ

明るいところで、真上から、画面の枠いっぱいに。横向きの名刺を縦に撮ってしまっても、
「回す」で直せる。ピントさえ合っていれば、電話番号は写真を見れば読める。

## 4つの画面

| タブ | 中身 |
| --- | --- |
| とる | 名刺を撮って、その場でしまう。下に「きょうしまった名刺」が並ぶ |
| さがす | 検索と一覧。新しい順・五十音・会社ごと・会った日順で並べ替えられる |
| あとで | やること／名前がまだ／ごぶさた の3つ。輪ゴムでは気づけなかったところ |
| 送る | 連絡先(.vcf)・CSV・本文の共有・バックアップ |

## 輪ゴムの束と比べて、便利なところ

- **探せる。** 「たしか名古屋の展示会で会った、印刷屋の人」——これで出てくる。
  ひらがな・カタカナ・「株式会社」のあるなしは区別しないので、うろ覚えでも引ける。
- **持ち歩ける。** 束は机の引き出しにしかないが、これは出先でも見られる。
- **紙には書けないことが一緒に残る。** 会った日・場所・顔の特徴・話した中身。
  半年後に電話をかけるとき、効くのは名刺の文字ではなくこのメモのほう。
- **そのまま電話・メールができる。** 番号をタップすればかかる。打ち間違えない。
- **スマホの電話帳に移せる。** 「連絡先に入れる」で、着信のときに名前が出るようになる。
- **年賀状や案内状の宛名がCSVで出る。** 束から住所を書き写す作業が消える。
- **ごぶさたが見える。** 半年以上会っていない人が「あとで」タブに並ぶ。
- **同じ人の2枚目に気づく。** 同じ名前の名刺をしまうと知らせる。肩書きが変わったのか、
  同姓の別人かが、その場でわかる。

## 不便なところ・できないこと

はじめて名刺アプリを使うなら、ここを先に読んでおくとよい。

- **文字の自動読み取り（OCR）はしていない。** 写真から名前や電話番号を勝手に
  拾ってはくれない。**名前と会社だけは自分で打つ**必要がある。
  逆に言えば、打つのはその2つでよい。残りは写真を見ればわかる。
  （自動で読み取る市販のアプリもあるが、月額がかかり、名刺を会社のサーバーに送ることになる）
- **この端末の中だけ。** パソコンとスマホで同じ箱を見ることはできない。
  人と共有することもできない。見せたいときはCSVか「この人を送る」で渡す。
- **黙って消えることがある。** iPhone の Safari は、しばらく開いていないサイトの
  データを消してしまうことがある。**ホーム画面に追加して**ときどき開き、
  **月に一度バックアップ**を取ること。これだけは省かないほうがよい。
- **写真は場所を食う。** 1枚あたり100KBくらい。1,000枚で100MB前後。
  「送る」タブの上に、いま使っている量が出る。
- **相手の異動や昇進は教えてくれない。** そこは大手の名刺サービスの仕事。
  ここでは、新しい名刺をもらったときに自分で足す。
- **バックグラウンドでは何もしない。** 通知も来ない。開いたときだけ動く。

### 紙の名刺は、すぐには捨てないほうがよい

慣れるまでの半年くらいは、束も残しておくとよい。
写真がぶれていた、バックアップを取り忘れた、というのは最初のうちに起きる。
「アプリを開けば全部ある」と自分で思えるようになってから、束を捨てればよい。

### 始め方（おすすめ）

いまの束を全部入れようとすると、たいてい途中でやめてしまう。

1. **まず、これからもらう分だけ入れる。** 1枚30秒。
2. そのうえで、**よく電話する相手だけ**束から探して10枚ほど入れる。
3. これで日常の用は足りる。残りの束は、必要になったときに1枚ずつ入れればよい。

## エクセル・電話帳に出す

送るタブから3種類。

| 出すもの | 中身 |
| --- | --- |
| 連絡先（.vcf） | スマホの電話帳に登録する形。ファイルを開くだけで入る |
| CSV「名簿ぜんぶ」 | 全項目。エクセルのA1に貼れば表になる |
| CSV「宛名だけ」 | 住所が入っている人だけ。年賀状・案内状の宛名印刷用 |

1人だけ電話帳に入れたいときは、さがすタブでその人を開いて「連絡先に入れる」。
このときは**名刺の写真も一緒に**入るので、電話帳でも名刺が見られる。

## バックアップ

送るタブから2種類。

- **写真つき** … 完全な控え。名刺の枚数によっては数十MBになる。パソコンやクラウドに置く。
- **文字だけ** … 軽い。名前・会社・メモは戻るが、名刺の写真は戻らない。

同じファイルを「バックアップから復元」で読ませると、そのまま元に戻る。
機種変更のときは、**必ず古い端末で写真つきを取ってから**移ること。

## 見た目

送るタブの「見た目」で **ふつう／かわいい**（黒紫とピンク）を切り替えられる。
端末ごとの設定で、記録には影響しない。明るい・暗いは端末の設定に自動で合う。

## 仕組み

- 名前やメモは localStorage、名刺の写真は IndexedDB に入れている。
  **どちらも端末の中だけ。サーバーには何も送らない。**
- 1ファイルで完結しているので、一度開いておけば圏外でも使える。
- 写真は取り込むときに長辺1400ピクセルまで縮めている（一覧用に小さい版も別に持つ）。
- 高速IC記録・ゆうちメモとは保存場所が別（キーは `meishi.v1`）。同じ端末で3つとも使える。

main に入れたあと、GitHub Pages で下記から開ける。

https://virgob77.github.io/ic-log/card/

**ホーム画面に追加**しておくと、1タップで開ける。名刺をもらう場面は急ぐので、
ホーム画面の1ページ目に置いておくとよい。

`file://` で直接開いた場合、ブラウザによっては写真を保存できないことがある。
そのときは画面の上に赤い断りが出る。公開版を使えばよい。

## 直すとき

`card/index.html` を書き換えるだけ。ビルドは要らない。

まず動きを見たいときは、送るタブの一番下の **「お試し用のサンプルを入れる」** で
架空の名刺7枚（うち1枚は名前なし、2枚はごぶさた）が入る。名刺の画像も作られる。
「記録をすべて削除」で消せる。
