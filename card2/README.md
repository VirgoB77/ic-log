# めいしばこ（試用版）

`card/` の新しい見た目を試すための版です。公開中の <https://virgob77.github.io/ic-log/card/> はそのまま残し、こちらは <https://virgob77.github.io/ic-log/card2/> で開けます。

- 中身（読み取り・保存・LINEで送る・地図・設定）は `card/` と同じです。
- 保存した名刺は同じ場所（この端末のブラウザの中）を使うので、どちらの URL で開いても同じ名刺が見えます。片方で保存すれば、もう片方にも出ます。
- 見た目は、デザイン案（3a・名刺帖の惑星モチーフ）のファイルを受け取り次第、この版に当てます。それまでは `card/` と同じ見た目です。

仕組みの説明は [card/README.md](../card/README.md) を見てください。
