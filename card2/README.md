# 名刺帖（めいしばこの試用版）

「めいしばこ」に、デザイン案 3a（名刺帖：墨×ライム・太陽系のボタン）の見た目を当てた版です。
公開中の <https://virgob77.github.io/ic-log/card/> はそのまま残し、こちらは <https://virgob77.github.io/ic-log/card2/> で開けます。

## 中身は同じ、見た目だけちがう

- 読み取り（端末の中の OCR と Claude で読む切りかえ）・保存・切り直し・回す・写真の文字を押して読み直す・連絡先に追加・LINEで送る・共有・地図・バックアップ・CSV は `card/` と同じ仕組みです。
- 保存した名刺は同じ場所（この端末のブラウザの中）を使うので、どちらの URL で開いても同じ名刺が見えます。片方で保存すれば、もう片方にも出ます。鍵（Claude・Google）も共通です。
- 写真は `card/` と同じく端末の中だけに残ります。

## 見た目の決まり（デザイン案 3a）

- 名前は「名刺帖」。色は墨×ライム（背景 `#0a0b09`、差し色 `#c9f24a`）。
- ボタンは太陽系。いちばんしてほしい操作が「太陽」（撮る・保存・電話・携帯・メール）、それ以外は「惑星」（丸い小さなボタン）、設定は右上の「月」、カメラのシャッターは「冥王星」。太陽を押すと軌道が広がって惑星が飛びます。
- 一覧：太陽（撮る）を画面の中央上に置き、軌道の小さな惑星が「写真から選ぶ」。名刺の一覧には写真を添え、いま保存した名刺には名前の横に太陽色の点が付きます。
- カメラ：四隅を見つけるとライム色の角で囲み、冥王星のまわりを衛星が回ります。静止すると輪がたまり、自動で撮ります。見つからないままだと白い輪が出ます。
- 新しい名刺：名前や会社の欄を押すと、写真のその部分が欄の上に出ます（端末の中で読んだときだけ）。右上の小さな写真を押すと写真が大きく開き、文字を押すとそこだけ読み直せます。✕＝やめる、太陽の✓＝保存。案内文は最小限にしています。
- 名刺の詳細：電話・携帯・メールは3つの太陽（番号だけ添える）。住所の右の惑星で Google マップを開き、鍵が入っていれば地図も出ます。下の並びは 連絡先・LINE・共有・編集。捨てるのは本文の最後にあります。

## 作り方

`card/index.html` を元に、見た目の部分（CSS・画面の骨組み・一覧や画面を組み立てる関数）だけを置きかえて作っています。読み取りの中身は同じファイルから来ているので、`card/` の読み取りを直したら、同じ手順でこの版も作り直せます。

仕組みの説明は [card/README.md](../card/README.md) を見てください。
