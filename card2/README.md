# 名刺帖

名刺を撮って読み取り、しまっておくアプリです。<https://virgob77.github.io/ic-log/card2/> で開けます。
見た目はデザイン案 3a（墨×ライム・太陽系のボタン）。前の版「めいしばこ」（`card/`）は引き上げて、`card/` は案内だけの転送ページにしました。

## できること

- 保存・切り直し・回す・写真の文字を押して読み直す・連絡先に追加・LINEで送る・共有・地図・バックアップ・CSV。
- 読み取りは Claude だけです（`claude-opus-5`）。鍵（APIキー）は常に入れておく前提で、端末の中の読み取り（Tesseract）と辞書の先読みはこの版にはありません。鍵が無いときは読み取らず、写真だけ残して名前を手で入れられます。Claude につながらなかったときは、わけを出して「もう一度読む」を押せます。
- 名刺と写真はこの端末のブラウザの中だけに残ります。前の版で保存した名刺も、同じ場所を使っているのでそのまま見えます。鍵（Claude・Google）も引き継がれます。

## 見た目の決まり（デザイン案 3a）

- 名前は「名刺帖」。色は墨×ライム（背景 `#0a0b09`、差し色 `#c9f24a`）。
- ボタンは太陽系。いちばんしてほしい操作が「太陽」（撮る・保存・電話・携帯・メール）、それ以外は「惑星」（丸い小さなボタン）、設定は右上の「月」、カメラのシャッターは「冥王星」。太陽を押すと軌道が広がって惑星が飛びます。
- 一覧：太陽（撮る）を画面の中央上に置き、軌道の小さな惑星が「写真から選ぶ」。名刺の一覧には写真を添え、いま保存した名刺には名前の横に太陽色の点が付きます。
- 並べ替え：「新しい順」の文字を押すと選べます。新しい順／会った日順／名前順（よみがあればよみで）／会社順／区分順／最近開いた順。選んだ順は覚えます。
- 縦の名刺：切らずに全体を入れ、空いたところは画面の地の色のままにします（枠も影も出しません）。横の名刺は枠いっぱいのままです。
- LINE のボタンは、緑の丸に白い吹き出しの LINE のマークです。
- カメラ：名刺を見つけると丸が名刺の上に移って光り、輪がゆっくりピコン、ピコンと広がります（四角の枠は出しません）。丸は一気に飛ばず、少しずつ寄せます。手ぶれ程度のゆれでは動かず、大きく動いたときだけ速く追いつきます。見失っても2秒は前の場所を保ちます。撮るのは冥王星のシャッターを押したときだけで、自動では撮りません。
- 四隅さがし：0.2秒ごとに、画面に見えているところだけを横360pxに縮めて調べます。名刺が画面の広さの5%より大きく写っていて（遠すぎない）、画面の縁にかかっていなければ（はみ出していない）「見つけた」とします。
- 切り取りの確認：撮ったあと（写真から選んだあとも）、どう切り取れたかを大きく見せます。下のボタンは 撮り直す（写真から選んだときは やめる）・回す・四隅を直す・読み取る で、文字つきです。読み取るを押して初めて Claude に送ります。
- 読み取りのついでの切り直し：Claude には、文字といっしょに「絵のどこに名刺があるか」の四隅も返してもらいます。名刺のまわり（机など）まで写っていたら、読み取りのあとで写真を切り直します。呼ぶ回数は増えないので、追加の料金はかかりません。すでにぴったり切れているとき（絵の95%以上）は何もしません。
- 新しい名刺：名前や会社の欄を押すと、写真のその部分が欄の上に出ます（端末の中で読んだときだけ）。右上の小さな写真を押すと写真が大きく開き、文字を押すとそこだけ読み直せます。✕＝やめる、太陽の✓＝保存。案内文は最小限にしています。
- 名刺の詳細：電話・携帯・メールは3つの太陽（番号だけ添える）。住所の右の惑星で Google マップを開き、鍵が入っていれば地図も出ます。下の並びは 連絡先・LINE・共有・編集。捨てるのは本文の最後にあります。
