# テナント誘致 推進表

土地・空き物件にテナントを誘致するときの管理を、いまのエクセル（推進表・案件一覧・
テナント名簿・成約）と同じ形のまま、スマホで持ち歩けるようにしたアプリ。

**移動中に連絡が来ても、その場で1行だけ残せる**ことを目当てに作ってある。

## エクセルとの対応

| エクセル | アプリ |
| --- | --- |
| 推進表（案件×テナントの1行） | **推進**タブ |
| 案件一覧 | **案件**タブ |
| テナント名簿 | **名簿**タブ |
| 成約シート | 推進の行に成約日を入れると自動で移る |
| メモ（新しい順に上へ追記） | 日付つきのメモを足すと自動で新しい順に積まれる |
| 状態列の数式 | 自動判定（下記） |
| 14日以上返事なしの赤 | 赤いバッジと「動き」タブの先頭 |

列の名前と並びはエクセルのままなので、**「送る」タブのCSVをコピーしてエクセルに
貼り付ければ元の表に戻せる**。

### 状態の自動判定（エクセルの数式と同じ）

| 条件 | 状態 |
| --- | --- |
| 情報開示日が空 | 未打診 |
| 開示済み・返事日が空 | 返事待ち ○日（14日を過ぎると赤） |
| 返事日あり・状況が空 | 返事あり（状況未入力） |
| 返事日あり・状況あり | 前向き（緑）／条件協議中（黄）／見送り（灰） |
| 成約日あり | 成約 |

## 使い方

1. スマホのブラウザで開く（公開版は下記）。
2. **名簿**タブ →「まとめて追加」に、いまのエクセルのテナント名簿の表をそのまま貼り付ける。
   **案件**タブでも同じように案件一覧を貼り付けられる。
3. 声をかけると決めた相手だけ、**推進**タブの「＋ 打診する相手を足す」で
   案件とテナントを選んで行を作る。
4. 資料を出したら情報開示日を入れる。ここから「返事待ち ○日」が数え始める。
5. 移動中に連絡が来たら、**動き**タブの大きい「メモを記録」を押して、
   相手を選び、やりとりを1行書く。状況（前向き／条件協議中／見送り）を選ぶと、
   返事日が空ならそのメモの日付で入る。
6. 月末に**送る**タブで、報告の本文をメール・LINEで送るか、CSVをエクセルに戻す。

### まとめて追加の並び

エクセルの表をコピーしてそのまま貼り付ければよい（見出し行が入っていても大丈夫）。

- テナント名簿 … テナント名 → 業種 → 窓口会社 → 代表担当者 → 連絡先 → 希望面積 → 備考
- 案件一覧 … 案件名 → 所在地 → 面積 → 用途地域 → 賃料想定 → 募集開始日 → 地主 →
  地主連絡先 → 貸主 → 貸主連絡先 → 備考

タブ区切り（エクセルからのコピー）でもカンマ区切りでも読める。
同じ名前がすでにあるものは飛ばす。

## 画面

| タブ | 中身 |
| --- | --- |
| 動き | 「メモを記録」の大ボタン／14日超・返事待ち・前向き・条件協議の数／返事が来ていない順／最近のメモ／まだ打診していない行 |
| 推進 | 推進表の一覧。案件で絞る・状態で絞る（14日超／返事待ち／未打診／前向き／条件協議中／見送り／成約）・メモの中身も検索できる |
| 案件 | 案件一覧。1件ごとに「打診 ○社（前向き1・返事待ち2…）」が出る |
| 名簿 | テナント名簿。打診中の件数つき |
| 送る | 報告の本文（メール・LINE・コピー）、CSV書き出し、バックアップ、全削除 |

## 仕組み

- 記録はブラウザの localStorage に保存する。**サーバーには何も送らない**。
- 1ファイルで完結しているので、圏外でも動く（初回に開いておけばよい）。
- 高速IC記録アプリとは保存場所が別（キーは `tenant-push.v1`）。同じ端末で両方使える。

### 制限

- 記録は端末の中にしかない。**機種変更の前に「送る」タブでバックアップ（.json）を取ること。**
  同じファイルから復元できる。
- 複数人での共有はできない。見せ合うときはCSVか報告の本文を送る。
- LINEへの送信は共有画面が開く方式（本文はコピー済みなので貼り付けるだけ）。

まず動きを見たいときは、送るタブの一番下の**「お試し用のサンプルを入れる」**で
架空の案件3件・テナント5社・推進5行・メモ7件が入る。「記録をすべて削除」で消せる。
