# テナント誘致台帳

土地・空き物件にテナントを誘致するときの、**接触の記録**をためていくスマホ用アプリ。
「どこに・いつ・何を話したか」と「次にやること」を、電話や訪問のあとにその場で一行だけ残す。

物件が10件前後、候補先が50社以上あっても、放置している先が出ないように作ってある。

## 使い方

1. スマホのブラウザで `tenant/index.html` を開く（公開版は下記）。
2. **物件**タブに、土地や空き物件を登録する（10件くらいなら手で入れられる）。
3. **候補先**タブに、当たっていく会社を登録する。
   50社以上あるときは「まとめて追加」でExcelの表をそのまま貼り付ける。
4. 電話・訪問・内見のあとに、**「接触を記録」**を押して内容と次にやることを残す。
5. 月末に**送る**タブで期間を選び、活動報告をメール／LINE／CSVで出す。

## 画面

| タブ | 中身 |
| --- | --- |
| 動き | 期限が来た「次にやること」、最近の記録、30日以上あいている先 |
| 候補先 | 会社の一覧。検索と絞り込み（要対応・進行中・未接触・温度A/B/C・成約・見送り） |
| 物件 | 土地・空き物件の一覧。1件ごとに「何社当たっているか」が出る |
| 送る | 活動報告の本文、CSV書き出し、バックアップ、全削除 |

### 記録の中身

- **接触の記録** … 日付／やり方（電話・訪問・内見・資料送付など）／対象物件／話した内容／進み具合
- **候補先** … 会社名・業種・担当者・連絡先・希望条件・温度感（A/B/C）・進み具合・対象物件・次にやること・メモ
- **物件** … 呼び名・種別（土地/建物/区画）・所在地・広さ・想定条件・募集状況・メモ

進み具合は「未接触 → 打診中 → 提案済 → 内見済 → 条件交渉 → 成約／見送り」の順。
接触を記録するときに変えると、その履歴にも残る。

「次にやること」は**候補先ごとに1つ**だけ持つ。日付を入れると「動き」タブの上に出て、
過ぎたものは赤く出る。

## 仕組み

- 記録はブラウザの localStorage に保存する。**サーバーには何も送らない**。
- 1ファイルで完結しているので、圏外でも動く（初回に開いておけばよい）。
- IC記録アプリとは保存場所が別（キーは `tenant-log.v1`）。同じ端末で両方使える。

### 制限

- 記録は端末の中にしかない。**機種変更の前に「送る」タブでバックアップ（.json）を取ること。**
  同じファイルから復元できる。
- 複数人での共有はできない。担当者どうしで見せ合うときは、CSVか活動報告の本文を送る。
- LINEへの送信は共有画面が開く方式（本文はコピー済みなので貼り付けるだけ）。

## 直すとき

`tenant/index.html` を書き換えるだけ。ビルドは要らない（IC記録アプリと違い、
差し込むデータがないため）。

まず動きを見たいときは、送るタブの一番下にある**「お試し用のサンプルを入れる」**で
架空の物件3件・候補先5社・記録8件が入る。「記録をすべて削除」で消せる。
