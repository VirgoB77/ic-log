# テナント誘致メモ

**電話が来たら、その場で書く。** それだけのためのメモ帳。
書いた時刻が自動で残り、「誰から・いつ・どんな連絡があったか」がそのまま記録になる。

テナント誘致版なので、書いたメモは相手（テナント）と案件にひもづき、
いまのエクセル（推進表・案件一覧・テナント名簿・成約）の形に自動で積み上がる。

## 使い方

1. アプリを開くと、いちばん上が**メモを書く枠**。まず書く。
2. 「だれから」で相手を選ぶ（よく連絡がある先が並ぶ。いなければ🔍で名簿から探す）。
   **相手が決まっていなくても保存できる**。あとから決めればよい。
3. 相手を選ぶと、その先に出している案件が出る。違えば選び直す。
4. 「保存する」。書いた日時つきで下に積まれる。

- 相手を選ぶと、**その先との前回までのやりとり（直近2件）**がメモ欄のすぐ上に出る。
  電話中に「前に何を話したか」を見ながら書ける。
- 相手なしで保存したメモは、上に**赤いお知らせ**が出る。タップして「だれから」を選べば片づく。
- 相手と案件をつけて保存すると、**推進表の行が自動でできる**（まだ無ければ）。
- 書きかけの文は自動で預かるので、途中で画面を閉じても消えない。
- パソコンなら Ctrl+Enter（Mac は ⌘+Enter）でも保存できる。

## 4つの画面

| タブ | 中身 |
| --- | --- |
| メモ | メモを書く枠と、これまでのメモ（日付ごと・時刻つき） |
| 推進 | エクセルの推進表。1行＝案件×テナント。状態は自動判定、14日超は赤。急ぐ順に並び、見送り・成約は下 |
| 台帳 | 案件一覧（所在地・面積・用途地域・賃料想定・募集開始日・地主・貸主・社内の担当）とテナント名簿 |
| 送る | 活動報告の本文（メール・LINE）、CSV書き出し、バックアップ |

## エクセルとの対応

| エクセル | アプリ |
| --- | --- |
| 推進表（案件×テナントの1行） | 推進タブ |
| メモ（新しい順に上へ追記） | メモそのもの。日時つきで自動的に新しい順 |
| 案件一覧 / テナント名簿 | 台帳タブ（列も並びもそのまま） |
| 成約シート | 推進の行に成約日を入れると自動で移る |
| 状態列の数式 | 自動判定（下記） |
| 14日以上返事なしの赤 | 赤いバッジ・推進タブの先頭・報告書の「返事が来ていない」 |

### 状態の自動判定（エクセルの数式と同じ）

| 条件 | 状態 |
| --- | --- |
| 情報開示日が空 | 未打診 |
| 開示済み・返事日が空 | 返事待ち ○日（14日を過ぎると赤） |
| 返事日あり・状況が空 | 返事あり（状況未入力） |
| 返事日あり・状況あり | 前向き（緑）／条件協議中（黄）／見送り（灰） |
| 成約日あり | 成約 |

情報開示日・返事日・状況・成約日は、推進タブで行をタップすると直せる。

## 名簿と案件の移し方

台帳タブの「まとめて追加」に、いまのエクセルの表をそのまま貼り付ける
（見出し行が入っていても大丈夫。タブ区切り・カンマ区切りどちらも読む。同じ名前は飛ばす）。

- テナント名簿 … テナント名 → 業種 → 窓口会社 → 代表担当者 → 連絡先 → 希望面積 → 備考
- 案件一覧 … 案件名 → 所在地 → 面積 → 用途地域 → 賃料想定 → 募集開始日 → 地主 →
  地主連絡先 → 貸主 → 貸主連絡先 → 社内の担当 → 備考

**「先にいまの一覧を消してから入れる」**にチェックを入れると、入れ替えになる。
そのとき推進の行も消える（メモは「案件なし」「相手なし」として残る）。

名簿にない相手から連絡が来たときは、🔍の検索欄に名前を打つと
「＋『◯◯』を名簿に追加」が出る。その場で登録してメモを続けられる。

## エクセルへ戻す

送るタブのCSVは5種類（メモ一覧・推進表・成約・案件一覧・テナント名簿）。
列の並びは元の表と同じで、推進表のメモ欄は
`9/2 11:40 本社で条件のすり合わせ…` のように**日時つき・新しい順**でセル内改行付きで出る。
コピーしてエクセルのA1に貼れば元の形に戻る。

## 仕組み

- 記録はブラウザの localStorage に保存する。**サーバーには何も送らない**。
- 1ファイルで完結しているので、圏外でも動く（初回に開いておけばよい）。
- 高速IC記録アプリとは保存場所が別（キーは `tenant-memo.v1`）。同じ端末で両方使える。

### 制限

- 記録は端末の中にしかない。**機種変更の前に「送る」タブでバックアップ（.json）を取ること。**
  同じファイルから復元できる。
- 複数人での共有はできない。見せ合うときはCSVか報告の本文を送る。
- LINEへの送信は共有画面が開く方式（本文はコピー済みなので貼り付けるだけ）。

## 直すとき

`tenant/index.html` を書き換えるだけ。ビルドは要らない。

まず動きを見たいときは、送るタブの一番下の**「お試し用のサンプルを入れる」**で
架空の案件3件・テナント5社・推進5行・メモ8件（うち1件は相手なし）が入る。
「記録をすべて削除」で消せる。
